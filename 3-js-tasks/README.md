# JavaScript Practice – Arrays, Promises, Symbols, and Logic

This folder contains multiple JavaScript programs written to practice **core JavaScript concepts** such as arrays, promises, spread operators, symbols, and logical problem solving.

---

## Concepts Covered

- Array operations (`shift`, `spread`, `reduce`, `filter`)
- Promise creation and handling (`resolve`, `reject`)
- Conditional logic based on data types
- Working with numbers, strings, and booleans
- Nested loops and pattern printing
- Use of `Symbol` as object keys
- Function chaining and data flow between functions
